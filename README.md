# CandleMC Website

## Run locally
1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Deploy
Upload this project to GitHub and import it into Vercel. Then connect your custom domain in Vercel.

## Important
Change `SERVER_IP` in `app/page.js` to your real Minecraft server address.
